# RoughSentinel

RoughSentinel enables real-time event-driven processing and low-latency data streaming, empowering a scalable Manager and Monitor of complex systems.

With RoughSentinel, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/RoughSentinel.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

RoughSentinel is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
